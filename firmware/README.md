# Firmware (Role A)
ESP32 code, Arduino IDE or PlatformIO. Library: "WebSockets" by Markus Sattler.
Put Wi-Fi name, password and the laptop's IP in `config.h` (gitignored - each person keeps their own).
Use the phone hotspot, not venue Wi-Fi.
Milestones: F1 LED, F2 mic, F3 stream to server, F4 speaker, F5 reconnect. No buttons: listening and feedback are controlled from the dashboard.
